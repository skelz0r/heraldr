# Heraldr

Télécommande de dispatch pour herdr : depuis l'iPhone, envoyer une
intention (écrite, dictée ou collée) au Claude principal d'un workspace
herdr, qui l'affine puis la dispatche dans un worktree via `/start`.

Usage personnel, installation locale sur l'appareil, pas de TestFlight.
