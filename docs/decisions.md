# Journal des décisions

Issu de la session de cadrage du 2026-10-10.

| Sujet | Décision | Écarté |
| --- | --- | --- |
| Positionnement | télécommande de dispatch, complément de Heeler | remplacer Heeler |
| Transport | SSH comme Heeler (streamlocal sur herdr.sock), LAN ou Tailscale | bridge HTTP, daemon |
| Côté Mac | plugin Heeler réutilisé tel quel, aucun code à nous | plugin forké |
| Pairing | QR `HERDR-PAIR:1` de `heeler.pair` | système maison |
| Lib SSH iOS | package HeelerSSH (libssh2) | Citadel |
| Focus | sélection de la cible dans l'app, rien côté Mac | `workspace focus` sur le Mac |
| Cible par défaut | toujours Home au lancement | dernier utilisé |
| Repérage de Home | workspace numéro 1 de herdr, quel que soit son label | label `~` (le workspace s'appelle parfois `Home`) |
| Agent cible | agent nommé `<slug>-main` dans le tab 1, créé s'il manque | adopter un Claude existant |
| Lancement | équivalent `dclaude` (yolo) via `herdr agent start --kind claude -- --dangerously-skip-permissions` | |
| Session Claude | nommée `<label>—main` en Remote Control | |
| Agent occupé | file d'attente, process détaché sur le Mac | refus, interruption, file dans l'app |
| Dispatch | /clear puis prompt + consigne FR qui impose /start | `/start <prompt>` direct |
| Questions de l'agent | autorisées (AskUserQuestion), réponse via Claude mobile ou le Mac | réponse dans l'app |
| Voix | SpeechAnalyzer + nettoyage Foundation Models, aperçu avant envoi | envoi auto, reformulation structurée |
| Flux | aperçu commun aux trois boutons | paste direct |
| États MVP | dot d'état agrégé par workspace | liste nue |
| Projet Xcode | XcodeGen + scripts bin/ | `.xcodeproj` versionné |
| Protos | HTML statiques (decision-mockups) | SwiftUI Previews |
| Bouton Coller | bouton sur mesure + « Toujours autoriser » dans Réglages | `PasteButton` système |
| Direction UI | D (cible en haut, grille en bas) avec un bouton voix d'environ 180 pt en bas, à la place du 128 pt | A, B, C |
| Intégration HeelerSSH | submodule git `Vendor/Heeler` épinglé, package local pour XcodeGen | copie vendorisée |
| Nom | Heraldr (Herald + herdr), bundle id `com.skelz0r.heraldr.dev` | Compagnon (provisoire), Stentor, Heraldz0r, Cooee… |
| Notifications | push au passage `blocked` des seuls agents `-main`, avec label, agent et question | notif `done`, Claude des worktrees |
| Envoi APNs | plugin herdr local (`pane.agent_status_changed`) qui signe le JWT et poste à APNs depuis le Mac, en Node sans dépendance | relay Cloudflare Worker, chiffrement AES-GCM, Notification Service Extension |
| Tap sur la notif | universal link `claude.ai/code/<session>` vers l'app Claude, repli sur Heraldr avec un bouton « Ouvrir dans Claude » | ouvrir Heraldr seulement |
| Token APNs | envoyé par SSH exec (`dispatch.sh register-push`), qui installe aussi le hook | fichier édité à la main |
| Logo | Voix et voies du premier tour, version noire (`5-voies-dark.svg`), palette vert d'eau puis recoloré en blanc, gris et vermillon avec la palette Graphite et gueules ; trait épaissi de 60 à 80 px pour l'icône | Éventail et ses variantes, Troupeau |
| Demande envoyée à Home | l'agent de Home identifie le projet (labels, cwd), demande si ambigu, relaie au `<slug>-main` du projet via `dispatch.sh relay` qui finit par /start ; sans projet, /start dans Home | /start depuis Home avec un tab dans le workspace du projet (faisait évoluer `/start`) |
| Historique des envois | 20 derniers envois sur l'iPhone, texte brut enregistré dès qu'on tape Envoyer puis statut suivi (en file, envoyé, échec) ; renvoi direct au workspace d'origine, erreur s'il n'existe plus ; copie vers le presse-papiers | historiser les seuls envois réussis, rouvrir l'aperçu prérempli, repli sur Home |
| Lexique de dictée | corrections apprises à l'envoi d'une dictée, sans confirmation : diff mot à mot entre texte proposé et texte envoyé, remplacements de 1 à 3 mots, 50 au plus, les plus récents d'abord ; réutilisées comme vocabulaire contextuel de SpeechAnalyzer et comme paires « entendu → voulu » dans la consigne du nettoyage (20 au plus, pour garder la fenêtre de contexte à la dictée) | confirmation « Retenir X → Y ? », remplacement textuel déterministe (faux positifs) |
| Dictée en plusieurs salves | « Dicter la suite » dans l'aperçu rouvre l'écran plein de dictée, la salve nettoyée seule s'ajoute à la fin du texte ; aussi depuis Écrire et Coller ; le lexique apprend à l'envoi chaque révision (texte proposé, texte juste avant la salve suivante), le texte déjà là avant une salve compte comme proposé | insertion au curseur, dictée inline dans l'aperçu, renettoyer tout le texte |
| Délégué des notifications | variantes à completion handler de `UNUserNotificationCenterDelegate`, `didReceive` rappelle UIKit depuis le main actor | variantes `async` : en Swift 6 le thunk rend la main à UIKit sur un thread coopératif, assertion de `_performBlockAfterCATransactionCommitSynchronizes:` et crash au tap app en arrière-plan ou tuée |
| Bords de la grille au défilement | barre Écrire / Coller en `safeAreaBar` du ScrollView, effet de bord `.soft` du système dessous ; en haut, masque en dégradé de 32 pt (remplacé par la cible en `safeAreaBar`) | effet de bord système en haut aussi : sans barre au-dessus de la grille il ne s'affiche pas, même avec une `safeAreaBar` vide ; bord net (`scrollEdgeEffectHidden`) |
| Taille de la cible | 38 % de l'écran en `safeAreaBar` du haut de la grille, nom en 44 pt pour tous ; effet de bord `.soft` du système plus fondu de 56 pt calé sur le bas de la cible, les tuiles disparaissent avant son texte | moitié haute et Home en 88 pt ; en-tête d'un quart de l'écran avec tuiles de 80 pt et état écrit (PR #12, annulée : trop compact, trop loin de l'ancien rendu) ; effet de bord seul (les tuiles restent visibles en fantôme derrière le texte de la cible) |
| Version affichée | 0.1.0 + SHA court (`-dirty` si sale) + date du build, écrits dans l'`Info.plist` du `.app` par un script post-build de `project.yml` (sandbox des scripts coupée sur la cible app pour lire `.git`) ; feuille Réglages ouverte par un bouton engrenage | bump manuel de `MARKETING_VERSION`, numéro de build auto-incrémenté, injection par les seuls `bin/` (rien depuis Xcode) |
| Gestion du lexique de dictée | liste dans les Réglages : balayer pour supprimer, modifier l'entendu comme le voulu, ajout à la main ; mêmes règles que l'apprentissage (1 à 3 mots par côté, entendu différent du voulu à la casse et aux accents près, remontée en tête, remplacement d'un entendu connu) pour qu'une paire saisie se comporte comme une paire apprise. Révise le refus initial d'un écran : une paire apprise de travers restait jusqu'à ce que 50 corrections plus récentes la chassent, sans moyen de la voir | pas d'écran (refus initial), « Tout vider », modifier le voulu seul, ajout libre sans limite de mots, garder la place d'une correction modifiée |
| Palette | « Graphite et gueules » : verre neutre et graphite, vermillon réservé à la voix ; tuile cible en verre plus clair sans teinte ; vert retiré des états (idle et done en gris « prêt », anneau ou pastille), gardé pour le seul Mac en ligne ; notice « envoyé » en gris ; Arrêter garde l'accent et se distingue par sa forme ; logo recoloré dans la même PR | vert d'eau d'origine (aplat sur la cible cerclé de blanc, trois verts en concurrence) ; Or du héraut, Aurore, Lagon (maquettes `heraldr-couleurs`) ; notice « envoyé » en vert ou en accent (rouge lu comme une erreur) ; Arrêter dans un rouge `recording` distinct, trop proche du vermillon |
| Bouton voix | « Goutte claire » : verre `.clear` de 92 pt sans teinte, micro et lueur radiale vermillon au fond ; Écrire et Coller en ronds de verre de 54 pt, sans capsule ; au défilement, l'effet de bord `.soft` déjà en place suffit à garder la goutte lisible ; sous Réduire la transparence, la lueur et le micro restent colorés sur le verre opaque | orbe teinté encastré dans la capsule, îlot séparé, fusion des verres, capsule « Dicter », lueur façon Apple Intelligence ; voile sombre sous la goutte |
| Pastille des tuiles | état de l'agent `<slug>-main`, même source que la cible (envoi en cours, agent absent compris) | `agent_status` agrégé de `workspace.list`, qui teint la tuile d'un autre tab ; pastille plus indicateur secondaire |
| Cible tab de worktree | appui long sur une tuile : menu des tabs du workspace qui ont un Claude (tab 1 exclu, il reste « main ») ; le premier Claude du tab, désigné par son `pane_id` puisque les Claude des worktrees n'ont pas de nom herdr ; texte précédé du seul avertissement de dictée, sans consigne (la consigne standard finit par /start, contraire à l'itération sur une feature lancée) ; `/clear` optionnel décoché pour garder le contexte de la session ; même file que les `-main` dans `dispatch.sh` (`enqueue-pane`) ; jamais de lancement de Claude dans un tab ; pas de persistance, un tap revient sur main | cible par nom d'agent (absent pour un Claude lancé par /start), donner un nom herdr au Claude du tab, garder la consigne standard, texte totalement brut (le Claude du tab ne sait pas qu'il peut contenir des erreurs de transcription), `/clear` toujours fait, mémoriser le dernier tab ciblé, feuille dédiée au lieu du menu contextuel |
| Positionnement révisé | compagnon de développement voice first et opinionated : lancer une idée vers un `<slug>-main` ou Home, puis itérer à la voix avec le Claude d'un worktree ; conventions herdr imposées et assumées, usage personnel | télécommande de dispatch seule (ne disait rien de l'itération sur un worktree ni des conventions dont tout dépend), client herdr généraliste (rôle de Heeler) |
