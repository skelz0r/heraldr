# Name candidates

Constraints: evoke herdr without colliding with Heeler (or Kelpie), so
no dog name; say what the app does (a voice that starts work remotely);
short, pronounceable in French and English.

Availability check done on 2026-10-10: `gh search repos <name> --limit
3` and an App Store web search. Personal use without publication: an
App Store collision only blocks if it is in the same domain (dev tools,
agents).

## Recommendation

Cooee. The Australian outback call to reach someone far away: that is
exactly the app (throwing an idea at the Mac from the street), and it
belongs with Heeler and Kelpie (Australian herding dogs) without being
a dog. Two syllables, no notable dev project on GitHub, App Store
collisions outside the domain (Sydney shuttles, avatar chat).

## Top 5

1. Cooee: see above
2. Holler: ranch-style "yell", a direct verb that describes the voice
   button; the only dev collision is a small notifications CLI (295
   stars)
3. Comebye: whistled command telling the sheepdog to circle the flock,
   so a dispatch order; namespace almost empty, but obscure outside
   shepherding
4. Drover: the human herder (not the dog); careful,
   `cloud-shuttle/drover` is already a parallel agent coordinator, and
   DroverDispatch exists on the App Store
5. Halloo: hunting cry to set the pack off; free on the App Store and
   GitHub, but unintuitive spelling

## Ruled out upfront

Dog names (Kelpie, Collie, Sheepdog, Bark, Fetch, Outrun): too close
to Heeler. Dispatch, Launch, Send: generic, no identity.

## Second round

Feedback on the first round: Herald is liked because it is
personified; look further on the sidekick side, and try blends with
"z0r" (skelz0r's signature). Same constraints: no dog, short,
pronounceable. Collisions: `gh search repos <name> --limit 3` for all,
App Store checked only for the short list. Scores out of 5, strict.

Note on z0r names: the home screen shows about 11 characters, all the
proposed ones fit. The "0" forces a switch to the number keyboard to
type the name, but Spotlight finds the app from "herald" or "herd", so
it almost never matters. The real cost is elsewhere: for a voice app,
"Hey Siri, open Heraldz0r" may not be recognised. To check on the
device; at worst the display name keeps the z0r and the app name stays
pronounceable.

### Second round top 10

1. Stentor (recommendation): a personified herald like Herald, but
   whose mythological attribute is the voice, so the button; rare
   proper noun, two syllables, no collision in the domain
2. Heraldz0r: the only z0r version that keeps a readable word intact;
   take it if z0r matters more than restraint, with the Siri risk
3. Herdz0r: reads right away as herdr's appendix; loses the
   personification
4. Igor: the funniest sidekick, "yes master" fits the gesture; Igorz0r
   exists as a variant
5. Harold: Herald turned colleague, with the meme as a bonus
6. Roger: butler and radio "received" in a single first name
7. Hark: the herald's call in four letters, but real voice collisions
   on GitHub and the App Store
8. Sancho: the canonical squire, short, no dev conflict
9. OuiChef: the best dispatch metaphor (order called, brigade going to
   its station), French and personal
10. Spawnz0r: the exact verb of worktree work, but no longer a
    sidekick

My 3 favourites across all rounds: Stentor, Heraldz0r, Cooee.
