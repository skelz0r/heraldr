# Noms candidats

Contraintes : évoquer herdr sans entrer en collision avec Heeler (ni
Kelpie), donc pas de nom de chien ; dire le geste de l'app (une voix qui
lance du travail à distance) ; court, prononçable en français et en
anglais.

Vérification de disponibilité faite le 2026-10-10 : `gh search repos
<nom> --limit 3` et une recherche web App Store. Usage personnel sans
publication : une collision App Store n'est bloquante que si elle est
dans le même domaine (outils dev, agents).

## Recommandation

Cooee. Le cri de l'outback australien pour appeler quelqu'un au loin :
c'est exactement l'app (lancer une idée vers le Mac depuis la rue), et
il fait famille avec Heeler et Kelpie (chiens de troupeau australiens)
sans être un chien. Deux syllabes, aucun projet dev notable sur GitHub,
collisions App Store hors domaine (navettes de Sydney, chat avatar).

## Top 5

1. Cooee : voir ci-dessus
2. Holler : « gueuler » façon ranch, verbe direct qui décrit le bouton
   voix ; seule collision dev, un petit CLI de notifications (295 étoiles)
3. Comebye : ordre sifflé au chien de berger pour partir tourner autour
   du troupeau, donc un ordre de dispatch ; namespace quasi vierge, mais
   obscur hors milieu du berger
4. Drover : le conducteur de troupeau humain (pas le chien) ; attention,
   `cloud-shuttle/drover` est déjà un coordinateur d'agents parallèles,
   et DroverDispatch existe sur l'App Store
5. Halloo : cri de chasse pour lancer la meute ; libre sur l'App Store
   et GitHub, mais orthographe peu intuitive

## Écartés d'office

Noms de chiens (Kelpie, Collie, Sheepdog, Bark, Fetch, Outrun) : trop
proches de Heeler. Dispatch, Launch, Send : génériques, aucune identité.

## Deuxième tour

Retour du premier tour : Herald plaît parce qu'il est personnifié ;
chercher plus loin côté acolyte, et tenter des mélanges avec « z0r »
(signature de skelz0r). Mêmes contraintes : pas de chien, court,
prononçable. Collisions : `gh search repos <nom> --limit 3` pour tous,
App Store vérifié seulement pour la short list. Notes sur 5, sévères.

Remarque sur les noms en z0r : l'écran d'accueil affiche environ
11 caractères, tous ceux proposés passent. Le « 0 » oblige à basculer
sur le clavier numérique pour taper le nom, mais Spotlight trouve l'app
dès « herald » ou « herd », donc ça ne gêne presque jamais. Le vrai
coût est ailleurs : pour une app vocale, « Dis Siri, ouvre Heraldz0r »
risque de ne pas être reconnu. À vérifier sur l'appareil ; au pire le
nom affiché garde le z0r et le nom de l'app reste prononçable.

### Top 10 du deuxième tour

1. Stentor (recommandation) : un héraut personnifié comme Herald, mais
   dont l'attribut mythologique est la voix, donc le bouton ; nom
   propre rare, deux syllabes, aucune collision dans le domaine
2. Heraldz0r : la seule version z0r qui garde un mot lisible intact ;
   à prendre si le z0r compte plus que la sobriété, avec le risque Siri
3. Herdz0r : se lit tout de suite comme l'appendice de herdr ; perd
   la personnification
4. Igor : le plus drôle des acolytes, « oui maître » colle au geste ;
   Igorz0r existe en variante
5. Harold : Herald devenu un collègue, avec le mème en prime
6. Roger : majordome et « reçu » radio dans un seul prénom
7. Hark : l'appel du héraut en quatre lettres, mais collisions
   vocales réelles sur GitHub et l'App Store
8. Sancho : l'écuyer canonique, court, aucun conflit dev
9. OuiChef : la meilleure métaphore du dispatch (commande annoncée,
   brigade qui part en poste), français et personnel
10. Spawnz0r : le verbe exact du travail en worktree, mais plus
    d'acolyte

Mes 3 préférés tous tours confondus : Stentor, Heraldz0r, Cooee.
